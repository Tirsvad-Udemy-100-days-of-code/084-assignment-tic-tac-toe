# Tic Tac Toe wiki

**English** · [Dansk](Home-da) · [Bahasa Melayu](Home-ms)

This is the wiki of the Tic Tac Toe game from Day 84 of Udemy's *100 Days of Code: The Complete Python Pro Bootcamp*: a text-based game for two players at one keyboard, written in Python 3.13 with no runtime dependency. The wiki explains what each of the four steps of the assignment gains you, and every step has a screenshot of the program's own output.

## Play it

After the set-up, one command starts the game:

```bash
python -m tic_tac_toe
```
