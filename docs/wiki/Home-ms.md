# Wiki Tic Tac Toe

[English](Home) · [Dansk](Home-da) · **Bahasa Melayu**

Ini ialah wiki permainan Tic Tac Toe dari hari ke-84 *100 Days of Code: The Complete Python Pro Bootcamp* Udemy: permainan berasaskan teks untuk dua pemain pada satu papan kekunci, ditulis dalam Python 3.13 tanpa kebergantungan semasa dijalankan. Wiki ini menerangkan apa yang anda peroleh daripada setiap satu daripada empat langkah tugasan, dan setiap langkah mempunyai tangkapan skrin output program itu sendiri.
