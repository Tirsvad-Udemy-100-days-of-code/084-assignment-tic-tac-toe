# Tic Tac Toe-wiki

[English](Home) · **Dansk** · [Bahasa Melayu](Home-ms)

Dette er wikien til Tic Tac Toe-spillet fra dag 84 i Udemys *100 Days of Code: The Complete Python Pro Bootcamp*: et tekstbaseret spil til to spillere ved ét tastatur, skrevet i Python 3.13 uden afhængigheder ved kørsel. Wikien forklarer, hvad hvert af opgavens fire trin giver dig, og hvert trin har et skærmbillede af programmets eget output.

| [Opsummering](Summary-da) | Hvad du har lært, trin for trin |

## Spil det

Efter opsætningen starter én kommando spillet:

```bash
python -m tic_tac_toe
```
